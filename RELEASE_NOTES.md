# LitWeave v0.1.0

This first public build adds a local-first Zotero literature map for Windows
10/11 x64.

- Manual paginated Zotero refresh with a Refresh Review tray.
- Persistent nested Collection frames, paper cards, Alias and ghost states.
- Local-only labelled relationships, notes, undo/redo canvas edits and
  JSON/SVG/PNG export.
- Right-click item location and PDF opening through Zotero attachment keys.
- No Zotero plugin, no Zotero writeback, no PDF copying and no AI/network
  suggestion provider in this release.

The installer is unsigned. Windows SmartScreen may show a warning; verify the
published SHA-256 file before installing.
